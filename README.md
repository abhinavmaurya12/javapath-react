# 🚀 JavaPath React

### A Modern Java & DSA Learning Platform

**JavaPath React** is a modern, interactive learning platform designed to help students learn **Core Java, Java Programming, and Data Structures & Algorithms (DSA)** through structured lessons, examples, practice problems, and an easy-to-use interface.

The project has been built using **React + Vite** with a focus on clean UI, responsive design, and an engaging learning experience.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abhinavmaurya12/javapath-react.git
```

### 2. Navigate to the project

```bash
cd javapath-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
